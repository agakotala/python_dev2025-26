Każdy plik:

- może być użyty jako materiał na zajęcia lub do samodzielnej nauki.

Uruchamianie:
1. Zainstaluj zależności:
   pip install -r requirements.txt
2. Uruchamiaj wybrany plik, np.:
   python 01_regresja_liniowa.py
