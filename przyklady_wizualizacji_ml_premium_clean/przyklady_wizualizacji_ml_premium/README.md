# Przyklady wizualizacji ML - wersja premium

Pakiet zawiera 3 bogatsze, bardziej efektowne przykłady wizualizacji:

1. `01_plotly_3d_klastry_premium.py`
   - interaktywny eksplorator klastrów 3D,
   - centroidy,
   - bogaty hover,
   - metryki klastrowania,
   - zapis HTML i CSV.

2. `02_pyvista_powierzchnia_regresji_premium.py`
   - powierzchnia regresji 3D,
   - kontury,
   - chmura punktów,
   - linie reszt,
   - ustawiona kamera i światła.

3. `03_dashboard_porownanie_modeli_premium.py`
   - dashboard 2x3,
   - ROC,
   - Precision-Recall,
   - macierz pomyłek,
   - ważność cech,
   - analiza progu decyzyjnego.

## Instalacja

```bash
pip install -r requirements.txt
```

## Uruchamianie

```bash
python 01_plotly_3d_klastry_premium.py
python 02_pyvista_powierzchnia_regresji_premium.py
python 03_dashboard_porownanie_modeli_premium.py
```
